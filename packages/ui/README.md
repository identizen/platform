# @identizen/ui

The Identizen design system: Tailwind v4 CSS-first tokens (`@identizen/ui/tokens.css`), the
theme controller (`@identizen/ui/theme`), shadcn primitives restyled through tokens only, the
theme toggle and the brand marks. Every Identizen surface uses it; ship TypeScript source, so a
Vite or Astro consumer compiles it with the app.
