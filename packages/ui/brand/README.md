# Identizen brand assets

The mark is 君 (*kimi*, "you"), constructed as a monoline on a 100-unit grid with an
8-unit stroke and round terminals. The wordmark is "identizen" set in Bricolage Grotesque
SemiBold and outlined to paths (SIL OFL), so no font needs to load. The hanko red
(`#E0412E`) appears in exactly one place per composition: the seal, or the first i's dot.

| File | Use |
| --- | --- |
| `kimi-mark.svg` | Inline mark, takes `currentColor`. Headers, favicons on plain grounds. |
| `kimi-seal.svg` | App icon, social avatar, favicon. Red seal with paper glyph. |
| `kimi-seal-ink.svg` / `kimi-seal-indigo.svg` | Seal on ink or the product accent, for dark grounds or in-app. |
| `identizen-wordmark.svg` | Wordmark with the red dot. Pair with `kimi-mark.svg`, never with the red seal. |
| `identizen-wordmark-plain.svg` | Wordmark, single color. Pair with the red seal. |
| `identizen-lockup.svg` | Ink mark + wordmark with red dot. Default horizontal lockup. |
| `identizen-lockup-seal.svg` | Red seal + plain wordmark. |
| `alt/` | Brush (Yuji Syuku) and display (Dela Gothic One) cuts of 君, other wordmark faces. |

Rules: clear space around the lockup equals the width of the 口 box. Minimum mark height 16 px,
minimum lockup height 20 px. Ink on paper, paper on sumi. Do not add gradients or outlines.
